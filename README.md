# Easy Gas ⛽

O **Easy Gas** é um aplicativo mobile desenvolvido para facilitar a busca por postos de combustíveis e a consulta de preços. A proposta é ajudar os usuários a encontrar postos próximos e comparar informações sobre combustíveis de maneira simples e intuitiva.

## Funcionalidades

- Visualização de postos em um mapa interativo.
- Identificação da localização atual do usuário.
- Busca por postos próximos.
- Cadastro de postos com localização no mapa.
- Armazenamento local das informações dos postos.
- Interface com configurações e opções de navegação.

## Tecnologias utilizadas

- **React Native** – Desenvolvimento da aplicação mobile.
- **Expo** – Ambiente de desenvolvimento e execução.
- **TypeScript** – Tipagem e organização do código.
- **Leaflet** – Exibição do mapa interativo.
- **OpenStreetMap** – Dados e mapas geográficos.
- **React Native WebView** – Integração do mapa com a aplicação.
- **AsyncStorage** – Armazenamento local de dados.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Salucatelli/easy_gas.git
```

2. Acesse a pasta do projeto:

```bash
cd easy_gas
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o Expo:

```bash
npx expo start
```

5. Utilize o aplicativo Expo Go ou um emulador para executar o projeto.
